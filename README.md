# Construction AI

AI project assistant for construction companies.

## Mission

Help construction companies capture and organize customer enquiries 24/7.

## Core Flow

Visitor → AI Assistant → Qualified Lead → Construction Team

## V1 Features

- Website chatbot
- Company knowledge system
- Service information
- FAQ answers
- Project qualification
- Lead capture
- Lead delivery

## Not Included In V1

- CRM
- Payments
- Accounting
- Dashboards
- Employee management
